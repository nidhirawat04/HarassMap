HARASSMAP
HarassMap is a community-based web application designed to help people report harassment and explore reported incidents across different locations. It aims to raise awareness and help users understand patterns of reported incidents through an interactive map.

Features:
  -Interactive Safety Map: Explore locations using Leaflet maps.
  -Incident Reporting: Submit reports with the incident type, description, location, and date.
  -Current Location: Use the browser's geolocation feature to identify your current coordinates.
  -Responsive Design: A clean interface designed for desktop and mobile screens.
  -Community Awareness: Encourage awareness of harassment and personal safety.

Technologies Used:
  -HTML5
  -CSS3
  -JavaScript
  -Leaflet.js
  -OpenStreetMap
